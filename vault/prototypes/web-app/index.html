A destructive confirmation names what it destroys. The entity, its parent, the connection and its environment, and the count read at this moment. The button stays disabled until the entity name is typed.

Purge active messages?

This deletes every active message in the queue. It cannot be undone.

A selection says exactly what it covers, and a result says what happened to each message. "3 selected of 20 loaded, 37 in the dead-letter queue" replaces a stored "all" flag. A message that was sent and could not be removed from the source is a possible duplicate, never offered for retry.
